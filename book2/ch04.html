Models on Your LaptopLaptop par Models

Haron has a secret twin that lives on your laptop. No internet, no API key, no bill. It's smaller and slower than the cloud models, but it's private, free and always there, which makes it perfect for learning, for prototypes, and for data that must never leave your machine. Every lab in this book was run on an ordinary laptop with 15 GB of RAM and no gaming GPU.

Haron ka ek gupt judwaa hai jo aapke laptop par rehta hai. Na internet, na API key, na bill. Yeh cloud models se chhota aur dheema hai, par private, free aur hamesha haazir, isliye seekhne, prototypes, aur aise data ke liye perfect hai jo kabhi machine se bahar nahi jaana chahiye. Is book ka har lab 15 GB RAM aur bina gaming GPU wale ek aam laptop par chala hai.

Will it fit?Kya fit hoga?

A model is a giant file of numbers. To run it, the whole file must fit in memory (RAM, or the GPU's memory). Quantisation stores each number in fewer bits, like saving a photo as a smaller JPEG: a little detail lost, much smaller file. At 4-bit quantisation, a model needs roughly 0.6 GB per billion parameters, plus room for the conversation.

Model numbers ki ek vishaal file hai. Chalaane ke liye poori file memory (RAM, ya GPU memory) mein aani chahiye. Quantisation har number ko kam bits mein rakhta hai, jaise photo ko chhoti JPEG ki tarah save karna: thodi detail gayi, file bahut chhoti. 4-bit quantisation par model ko lagbhag har arab parameter par 0.6 GB chahiye, aur baatcheet ke liye jagah.

The price of thinking, measuredSochne ki keemat, naap kar

Qwen3 is a "thinking" model: it can reason privately before answering. We asked it one short question three ways on this laptop. The answer was the same one sentence each time. The work was not.

Qwen3 ek "thinking" model hai: jawab dene se pehle chupchaap soch sakta hai. Humne is laptop par use ek chhota sawaal teen tarah se poocha. Har baar jawab wahi ek sentence tha. Mehnat nahi.

AI behaviour

Switches don't always work the way the docs saySwitches hamesha docs jaise kaam nahi karte

In our run, think: false still produced about 330 tokens of reasoning inside the answer, and adding /no_think to the prompt made the model think six times longer. Behaviour depends on the model version, the runtime version and the chat template. Never assume; measure tokens and time for the exact setup you will ship.

Hamare run mein think: false ke baad bhi jawab ke andar lagbhag 330 tokens ki reasoning aayi, aur prompt mein /no_think jodne se model ne chhe guna lamba socha. Behaviour model version, runtime version aur chat template par depend karta hai. Kabhi maan kar mat chalo; jo setup ship karoge uske tokens aur samay naapo.

Ollama, LM Studio and vLLM all offer an OpenAI-compatible endpoint. Write your app against that shape (or a small adapter, as in Book 2), and switching between your laptop model and a paid API becomes a one-line config change. Laptop par free develop karo; majboot model par tabhi jao jahan evals kahein.

In the real world

Laptop models in companiesCompanies mein laptop models

Teams use local models for offline demos, for working with confidential documents that can't go to a cloud API, for cheap bulk pre-processing, and on new "AI PCs" with NPUs built for this. Check your company's policy before downloading model weights onto a work laptop: licences and security reviews apply.

Teams local models use karti hain offline demos ke liye, aise confidential documents ke saath kaam ke liye jo cloud API par nahi ja sakte, saste bulk pre-processing ke liye, aur naye "AI PCs" par jinme iske liye NPUs bane hain. Office laptop par model weights download karne se pehle company ki policy check karo: licences aur security reviews laagu hote hain.

Deep dive: GGUF and quantisation namesGehraai mein: GGUF aur quantisation ke naamadvanced

GGUF is the file format used by llama.cpp and Ollama. Its names describe the quantisation: Q8_0 (8-bit, near-original quality), Q5_K_M, Q4_K_M (4-bit, the usual sweet spot), Q3_K_S/Q2_K (smaller, noticeably worse). "K" variants quantise in blocks with per-block scales; "M/S/L" choose how many layers keep higher precision. Memory ≈ parameters × bits ÷ 8, plus the KV cache, which grows with context length. Speed on CPU is mostly limited by memory bandwidth: a 4B model at 4-bit reads about 2.5 GB per token, so DDR5 laptops reach tens of tokens per second, while a GPU with fast VRAM is several times faster.

GGUF llama.cpp aur Ollama ka file format hai. Iske naam quantisation batate hain: Q8_0 (8-bit, lagbhag asli quality), Q5_K_M, Q4_K_M (4-bit, aam sweet spot), Q3_K_S/Q2_K (chhote, saaf kharab). "K" variants blocks mein quantise karte hain, har block ka scale; "M/S/L" tay karte hain kitni layers zyaada precision rakhein. Memory ≈ parameters × bits ÷ 8, aur KV cache, jo context ke saath badhta hai. CPU par speed zyaadatar memory bandwidth se limited hai: 4-bit par 4B model har token par lagbhag 2.5 GB padhta hai, isliye DDR5 laptops dasiyon tokens per second tak pahunchte hain, jabki tez VRAM wala GPU kai guna tez hai.

What we learnedHumne kya seekha

  1. At 4-bit, budget about 0.6 GB of memory per billion parameters, plus room to talk.
  2. Ollama gets you running in minutes, with an API your code can call.
  3. Laptop models are free and private, but smaller and slower.
  4. Thinking costs time and tokens; measure your exact setup.
  1. 4-bit par har arab parameter ke liye lagbhag 0.6 GB memory, aur baat karne ki jagah rakho.
  2. Ollama minutes mein chalu kar deta hai, ek API ke saath jise code call kar sake.
  3. Laptop models free aur private hain, par chhote aur dheeme.
  4. Sochne mein samay aur tokens lagte hain; apna setup naapo.
