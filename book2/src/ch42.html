Two limits keep showing up in this book. A single answer from a model can be wrong in a way it would have caught on a second try. And a model can't learn from yesterday: its weights froze when training ended. This chapter covers the practical tools for both. For reasoning: self-consistency (ask several times, take the majority) and tree of thoughts (explore several approaches, keep the best). For learning over time: episodic memory, and an honest look at continual learning.

Aur model kal se seekh nahi sakta: training khatam hote hi uske weights jam gaye. Yeh chapter dono ke practical tools batata hai. 1

Spending more compute at answer timeJawab ke samay zyaada compute lagaana

There are two ways to get a better answer: a bigger model, or more work from the same model at answer time. The second is called test-time compute, and research since 2024 (the idea behind reasoning models, Ch 9) shows it often pays off: up to a point, more thinking, more attempts or more checking buys accuracy. Reasoning models do it inside one call. The two techniques below do it from the outside, with any model, in your harness.

Behtar jawab ke do tareeke hain: bada model, ya usi model se jawab ke samay zyaada kaam. Doosre ko test-time compute kehte hain, aur 2024 se research (reasoning models ke peeche ka idea, Ch 9) dikhaati hai ki yeh aksar faayda deta hai: ek hadd tak, zyaada soch, zyaada koshishein ya zyaada jaanch sateekta khareedti hai. Reasoning models yeh ek call ke andar karte hain. Neeche ke do tareeke ise bahar se, kisi bhi model ke saath, aapke harness mein karte hain.

2

Self-consistency: ask five times, trust the majoritySelf-consistency: paanch baar poochho, bahumat par bharosa

Ask the same question several times with some randomness (temperature above 0), extract each final answer, and take the most common one. Mistakes tend to be scattered; correct reasoning tends to land in the same place. It costs N times the tokens, so use it where an answer is checkable and errors are expensive: maths, extraction, classification with consequences.

Wahi sawaal kuch randomness ke saath (temperature 0 se upar) kai baar poochho, har aakhri jawab nikaalo, aur sabse aam wala lo. Galtiyan bikhri hoti hain; sahi soch aksar ek hi jagah pahunchti hai. Kharch N guna tokens, isliye wahan use karo jahan jawab jaancha ja sake aur galti mehengi ho: hisaab, extraction, nateejon wali classification.

3

Tree of thoughts: explore before you commitTree of thoughts: pakka karne se pehle aazmaao

For open problems (plans, designs, puzzles) there isn't one answer to vote on. Tree of thoughts asks the model for several different approaches, has it (or a checker) score each one, and expands only the most promising branch, sometimes backtracking if it hits a dead end. It's how a good engineer works: sketch three options, pick one with reasons, then go deep.

Khule sawaalon (plans, designs, paheliyan) mein vote karne ke liye ek jawab nahi hota. Tree of thoughts model se kai alag raaste maangta hai, unhe model (ya checker) se score karwaata hai, aur sirf sabse ummeed wali shaakha badhaata hai, kabhi band raaste par peeche bhi aata hai. Achha engineer aise hi kaam karta hai: teen vikalp kheencho, kaaran ke saath ek chuno, phir gehre jao.

4

Episodic memory: remembering what happenedEpisodic memory: jo hua use yaad rakhna

Chapter 15 stored facts about a user ("vegetarian, lives in Pune"). Episodic memory stores events: what went wrong last time, and what fixed it. After each conversation, the model writes a one-line summary (problem + fix), saved with its date and an embedding. When a new conversation starts, the most similar past episodes are recalled into the context. The assistant seems to "learn from experience", without any change to its weights.

Chapter 15 ne user ke baare mein facts store kiye ("vegetarian, Pune mein rehti hai"). Episodic memory ghatnaayein store karti hai: pichhli baar kya bigda, aur kisne theek kiya. Har baatcheet ke baad model ek-line saar likhta hai (samasya + ilaaj), tareekh aur embedding ke saath save. Nayi baatcheet shuru hone par sabse milti-julti purani ghatnaayein context mein laayi jaati hain. Assistant "anubhav se seekhta" lagta hai, uske weights mein bina kisi badlaav ke.

AI behaviour

Continual learning: why models don't just keep learningContinual learning: models bas seekhte kyun nahi rehte

Updating a model's weights on every new conversation sounds ideal, but it runs into catastrophic forgetting (new training overwrites old skills), safety risks (anyone could teach it bad habits), and cost. So today's products fake it: memory and retrieval for knowledge, periodic fine-tunes (Ch 23) for behaviour, each checked by evals. True continual learning is an active research area; treat claims about it with the checklist from Chapter 35.

Har nayi baatcheet par model ke weights update karna aadarsh lagta hai, par yeh catastrophic forgetting (naya training purane hunar mita deta hai), suraksha ke khatron (koi bhi use buri aadatein sikha sakta hai) aur kharch se takraata hai. Isliye aaj ke products iska dikhava karte hain: gyaan ke liye memory aur retrieval, behaviour ke liye samay-samay par fine-tunes (Ch 23), har ek evals se jaancha. Asli continual learning sakriya research hai; iske daavon ko Chapter 35 ki checklist se parkho.

What we learnedHumne kya seekha

  1. Test-time compute: more work at answer time often beats a bigger model, up to a point.
  2. Self-consistency samples several answers and takes the majority; best for checkable answers.
  3. Tree of thoughts proposes approaches, scores them, and expands the best.
  4. Episodic memory stores dated summaries of past events and recalls the relevant ones.
  5. Continual learning in weights is still research; products use memory, retrieval and periodic fine-tunes.
  1. Test-time compute: jawab ke samay zyaada kaam aksar bade model se behtar, ek hadd tak.
  2. Self-consistency kai jawab le kar bahumat chunti hai; jaanchne laayak jawabon ke liye best.
  3. Tree of thoughts raaste sujhaata, unhe score karta, aur sabse achha badhaata hai.
  4. Episodic memory purani ghatnaon ke tareekh wale saar rakhti aur kaam ke yaad karti hai.
  5. Weights mein continual learning abhi research hai; products memory, retrieval aur samay-samay ke fine-tunes use karte hain.
