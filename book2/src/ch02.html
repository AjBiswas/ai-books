1

One word at a timeEk baar mein ek word

A large language model (LLM) does exactly one thing: given some text, it predicts the next small piece of text, called a token. To write a paragraph, it predicts one token, adds it to the text, and predicts again, hundreds of times.

Large language model (LLM) bilkul ek kaam karta hai: kuch text diya jaaye toh agla chhota tukda predict karta hai, jise token kehte hain. Paragraph likhne ke liye woh ek token predict karta hai, text mein jodta hai, aur phir predict karta hai, saikadon baar.

2

Haron has no memoryHaron ki koi memory nahi

This surprises everyone: the model remembers nothing between requests. Chat apps feel like they remember because the app re-sends the whole conversation every time. Everything the model can see at once is the context window, measured in tokens.

Yeh sabko hairaan karta hai: model do requests ke beech kuch yaad nahi rakhta. Chat apps ko lagta hai ki woh yaad rakhti hain kyunki app har baar poori baatcheet dobara bhejti hai. Model ek baar mein jo kuch dekh sakta hai woh hai context window, tokens mein naapi jaati hai.

RememberYaad rakho

Rule of thumb for English: 1 token ≈ 4 characters ≈ ¾ of a word. Hindi and other Indian languages usually need more tokens for the same meaning. You pay per token, both for what you send (input) and for what the model writes (output, usually several times pricier).

English ke liye mota hisaab: 1 token ≈ 4 characters ≈ ¾ word. Hindi aur doosri Indian bhashaon mein same matlab ke liye aksar zyaada tokens lagte hain. Aap har token ka paisa dete ho, jo bhejte ho (input) aur jo model likhta hai (output, aksar kai guna mehenga), dono ka.

3

Chances, not answersJawab nahi, chances

For the next token, the model actually produces a chance for every possible token. Then a dice-roll picks one. Temperature controls how adventurous that roll is: low means "almost always pick the favourite", high means "give the long shots a chance". That's why the same question can get different answers.

Agle token ke liye model asal mein har mumkin token ka chance banata hai. Phir ek paasa ek ko chunta hai. Temperature tay karta hai paasa kitna himmatwala ho: kam matlab "lagbhag hamesha pasandeeda chuno", zyaada matlab "kamzor options ko bhi mauka do". Isliye same sawaal ke alag jawab aa sakte hain.

AI behaviour

Fluent is not the same as trueSaaf bolna sach bolna nahi hai

The model picks likely-sounding tokens. When it knows the answer, likely and true line up. When it doesn't, it still produces something likely-sounding, in the same confident voice. This is hallucination, and it's why much of AI engineering is about giving the model real facts (Chapter 14) and checking its output (Chapter 26).

Model vishwasniya lagne wale tokens chunta hai. Jab use jawab pata ho, vishwasniya aur sach ek ho jaate hain. Jab na pata ho, tab bhi woh vishwasniya lagne wala kuch bolta hai, usi yakeen bhari awaaz mein. Ise hallucination kehte hain, aur isi wajah se AI engineering ka bada hissa model ko asli facts dene (Chapter 14) aur uska output check karne (Chapter 26) ke baare mein hai.

Engineer's note

Three numbers to check for any modelKisi bhi model ke teen numbers check karo

(1) Context window: how much it can read at once (8K to 1M+ tokens today). (2) Price per million input and output tokens. (3) Speed: time to first token and tokens per second. Chapter 3 adds quality and licence to this list.

(1) Context window: ek baar mein kitna padh sakta hai (aaj 8K se 1M+ tokens). (2) Har million input aur output tokens ka daam. (3) Speed: pehla token aane ka samay aur tokens per second. Chapter 3 is list mein quality aur licence jodta hai.

Deep dive: what's inside (one paragraph)Gehraai mein: andar kya hai (ek paragraph)advanced

Text is split into tokens by a tokenizer; each token becomes a vector (a list of a few thousand numbers). These vectors pass through dozens of transformer layers. In each layer, attention lets every token gather information from earlier tokens, and an MLP transforms it. The final layer outputs a score (logit) for every token in the vocabulary; softmax turns scores into probabilities; the sampler picks one. Generation is autoregressive: the chosen token is appended and the process repeats, with a KV cache so earlier work isn't redone. Book 2, Chapter 1 animates every step.

Tokenizer text ko tokens mein kaatta hai; har token ek vector ban jaata hai (kuch hazaar numbers ki list). Yeh vectors darjanon transformer layers se guzarte hain. Har layer mein attention har token ko pehle ke tokens se jaankari lene deta hai, aur ek MLP use badalta hai. Aakhri layer vocabulary ke har token ka score (logit) deti hai; softmax scores ko probabilities banata hai; sampler ek chunta hai. Generation autoregressive hai: chuna hua token joda jaata hai aur process dohraaya jaata hai, KV cache ke saath taaki pehle ka kaam dobara na ho. Book 2 ka Chapter 1 har step animate karta hai.
