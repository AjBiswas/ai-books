In 2023 everyone talked about prompt engineering: the right words. By 2025 the conversation moved to context engineering: the right everything. Haron only knows what's in its context window at that moment: the instructions, the tool list, the documents, the memory, the conversation, the tool results. Deciding what goes in, in what order, and what stays out is the biggest lever on quality and cost in any serious AI app.

2023 mein sab prompt engineering ki baat karte the: sahi shabd. 2025 tak baat context engineering par aa gayi: sahi sab kuch. Haron sirf wahi jaanta hai jo us pal uski context window mein hai: instructions, tools ki list, documents, memory, baatcheet, tool results. Kya andar jaaye, kis order mein, aur kya bahar rahe, yeh tay karna kisi bhi gambhir AI app mein quality aur kharch ka sabse bada lever hai.

What's in the window?Window mein kya hai?

The ruleNiyam

Find the smallest set of high-signal tokens that lets Haron do the task well. Every extra token costs money, adds latency, and dilutes attention. Order from stable to changing, so the prompt cache can reuse the front (Chapter 29).

Aise sabse chhote, sabse kaam ke tokens dhoondho jinse Haron kaam achhe se kar sake. Har extra token paisa leta hai, der badhaata hai, aur dhyaan bikherta hai. Sthir se badalte ki taraf order karo, taaki prompt cache aage ka hissa reuse kar sake (Chapter 29).

2

Pack everything, or fetch when needed?Sab pack karo, ya zaroorat par laao?

Old approach: stuff every possibly-useful document into the prompt. New approach, used by coding agents like Claude Code: give the model tools to look things up (search, read a file, list a folder) and lightweight pointers (file names, a skill index), and let it pull in only what it needs, when it needs it. Like a person who knows where the library is instead of carrying every book.

Purana tareeka: har kaam aa sakne wala document prompt mein thoos do. Naya tareeka, jo Claude Code jaise coding agents use karte hain: model ko cheezein dhoondhne ke tools do (search, file padhna, folder dekhna) aur halke pointers (file names, skill index), aur use sirf wahi laane do jo chahiye, jab chahiye. Jaise insaan jo har kitaab uthaane ki jagah jaanta hai library kahan hai.

3

Four ways to keep the window cleanWindow saaf rakhne ke chaar tareeke

AI behaviour

Context rotContext rot

As the window fills, models get worse at finding and combining facts, even far below the advertised limit. They also tend to remember the start and end better than the middle. A million-token window is a capability, not a target: a 20,000-token context with the right material usually beats 500,000 tokens with everything.

Window bharne ke saath models facts dhoondhne aur jodne mein kharab hote jaate hain, bataayi gayi limit se bahut neeche bhi. Woh shuruaat aur ant ko beech se behtar yaad rakhte hain. Million-token window ek kaabiliyat hai, lakshya nahi: sahi saamagri wala 20,000-token context aksar sab kuch wale 500,000 tokens ko hara deta hai.

Engineer's note

Look at the actual contextAsli context dekho

When an agent misbehaves, the first debugging step is to print the exact context it saw at the step where it went wrong. Nine times out of ten the cause is visible: a stale tool result, a contradictory instruction, a 40-page dump, a missing fact. Log full contexts in development (and carefully, without personal data, in production).

Jab agent galat kare, debug ka pehla step hai woh sateek context print karna jo usne dekha us step par jahan galti hui. Das mein se nau baar wajah dikh jaati hai: purana tool result, ulta instruction, 40 page ka dump, gaayab fact. Development mein poore contexts log karo (aur production mein dhyaan se, bina personal data ke).

In the real world

Context engineering is most of the jobContext engineering hi kaam ka bada hissa hai

Teams that build strong agents report spending more time on what goes into the context (tool design, retrieval quality, compaction, memory) than on the wording of the system prompt. Book 2, Chapter 8 shows a working context manager with compaction you can reuse.

Majboot agents banaane wali teams batati hain ki woh system prompt ke shabdon se zyaada samay context mein kya jaata hai (tool design, retrieval quality, compaction, memory) par lagaati hain. Book 2 ka Chapter 8 compaction ke saath chalne wala context manager dikhata hai jo aap reuse kar sakte ho.

What we learnedHumne kya seekha

  1. Context is everything I see: instructions, tools, documents, memory, history, results.
  2. Give me the smallest set of high-signal tokens, ordered stable to changing.
  3. Let me fetch information just in time with tools instead of pre-loading everything.
  4. Fight context rot with compaction, notes, sub-agents and clearing old tool results.
  1. Context woh sab hai jo main dekhta hoon: instructions, tools, documents, memory, history, results.
  2. Mujhe sabse chhote, kaam ke tokens do, sthir se badalte ke order mein.
  3. Sab pehle load karne ki jagah mujhe tools se zaroorat par jaankari laane do.
  4. Context rot se compaction, notes, sub-agents aur purane tool results saaf karke lado.
