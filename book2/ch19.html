Skills, Plugins & Sub-agentsSkills, Plugins aur Sub-agents

"Can we teach Haron our way of filing GST returns?" People imagine this needs retraining the model. It almost never does. There's a ladder of ways to add a skill, from a paragraph in the prompt to a full fine-tune, and the cheap rungs solve most needs. The newest rung, Agent Skills, packages know-how into a folder Haron loads only when it needs it.

"Kya hum Haron ko apna GST return file karne ka tareeka sikha sakte hain?" Log sochte hain iske liye model retrain karna padega. Lagbhag kabhi nahi. Skill jodne ki ek seedhi hai, prompt ke ek paragraph se poore fine-tune tak, aur saste daande zyaadatar zaroorat poori kar dete hain. Sabse naya daanda, Agent Skills, gyaan ko ek folder mein pack karta hai jise Haron sirf zaroorat par load karta hai.

How a Skill loadsSkill kaise load hoti hai

A Skill is a folder with a SKILL.md file: a short name and description at the top, step-by-step instructions below, and optional scripts, templates and reference files alongside. The trick is progressive disclosure: only the one-line descriptions sit in Haron's context all the time. The full instructions load when a task matches, and the extra files only when a step needs them. You can install hundreds of skills without filling the window.

Skill ek folder hai jisme SKILL.md file hoti hai: upar chhota naam aur description, neeche step-by-step instructions, aur saath mein optional scripts, templates aur reference files. Chaabi hai progressive disclosure: Haron ke context mein hamesha sirf ek-line descriptions rehti hain. Poore instructions tab load hote hain jab kaam match kare, aur extra files tabhi jab kisi step ko chahiye. Aap window bhare bina saikadon skills install kar sakte ho.

skills/gst-return/SKILL.mdmarkdown
---
name: gst-return
description: Prepare a monthly GSTR-3B summary from the sales ledger. Use when someone asks to prepare or check a GST return.
---
# Preparing GSTR-3B

1. Read the ledger with `read_sheet`. Group taxable value by rate: 5%, 12%, 18%, 28%.
2. Run `scripts/reconcile.py ledger.xlsx gstr2b.json` to match input tax credit.
3. Fill `templates/gstr3b.json`. Explain any mismatch above ₹1,000.
4. Never submit. Hand the draft to a human for review and filing.

Engineer's note

Writing a skill that triggersAisi skill likhna jo sahi waqt chale

The description decides when Haron reaches for the skill, so write it like a search result: what it does and when to use it, with the words users actually say ("GST", "return", "GSTR-3B"). Keep SKILL.md short and move long references into separate files the steps point to. Put deterministic work (calculations, file conversions) in scripts: code is cheaper and more reliable than tokens.

Description tay karti hai Haron skill kab uthaata hai, isliye ise search result ki tarah likho: kya karti hai aur kab use karni hai, unhi shabdon mein jo users bolte hain ("GST", "return", "GSTR-3B"). SKILL.md chhoti rakho aur lambe references alag files mein daalo jinki taraf steps ishaara karein. Pakka kaam (hisaab, file conversion) scripts mein rakho: code tokens se sasta aur bharosemand hai.

AI behaviour

Skills can carry hidden instructionsSkills chhupe instructions bhi la sakti hain

A skill is instructions Haron will follow, plus code it may run. A skill downloaded from a stranger can tell Haron to send files somewhere, or ship a script that does. Read every third-party skill before installing it, just as you'd read a script before running it with admin rights.

Skill woh instructions hain jo Haron maanega, aur code jo woh chala sakta hai. Kisi anjaan se download ki skill Haron ko files kahin bhejne ko keh sakti hai, ya aisa script la sakti hai jo yeh kare. Install karne se pehle har teesre ki skill padho, jaise admin rights se chalaane se pehle script padhte ho.

In the real world

A company skills libraryCompany ki skills library

Teams turn their playbooks into shared skills: "how we write release notes", "our brand voice", "how to triage a P1 incident", "our SQL conventions". Version them in Git, review changes like code, and distribute them as plugins so every employee's AI assistant follows the same playbook. The same idea appears under other names: Custom GPTs in ChatGPT, Gems in Gemini, project instructions in many tools.

Teams apni playbooks ko shared skills banaati hain: "hum release notes kaise likhte hain", "hamari brand awaaz", "P1 incident ka triage kaise", "hamare SQL niyam". Inhe Git mein version karo, badlaav code ki tarah review karo, aur plugins ki tarah baanto taaki har employee ka AI assistant same playbook maane. Yahi idea doosre naamon se bhi hai: ChatGPT mein Custom GPTs, Gemini mein Gems, kai tools mein project instructions.

For coders: a sub-agent definitionCoders ke liye: sub-agent definitionmarkdown
.claude/agents/sql-reviewer.md (Claude Code style)markdown
---
name: sql-reviewer
description: Reviews SQL migrations for locking, missing indexes and data loss. Use before merging any migration.
tools: Read, Grep, Glob
---
You are a careful database reviewer. For each migration file:
1. Flag statements that lock large tables (ALTER on big tables, missing CONCURRENTLY).
2. Flag DROP or destructive UPDATE without a backup step.
3. Reply with a short table: file, line, risk, fix.

The main agent hands the sub-agent a task; the sub-agent works in its own fresh context with only read tools, and returns just the table. That keeps the main context clean and the reviewer unable to change anything.

Main agent sub-agent ko kaam deta hai; sub-agent apne naye context mein sirf read tools ke saath kaam karta hai, aur sirf table lautaata hai. Isse main context saaf rehta hai aur reviewer kuch badal nahi sakta.

What we learnedHumne kya seekha

  1. Add skills from the cheapest rung up: prompt, knowledge, tools, Skills, sub-agents, and only then fine-tuning.
  2. A Skill is a folder of instructions and scripts, loaded only when needed.
  3. Good descriptions make skills trigger at the right time.
  4. Read third-party skills before installing; share company skills through plugins.
  1. Skills sabse saste daande se jodo: prompt, gyaan, tools, Skills, sub-agents, aur tabhi fine-tuning.
  2. Skill instructions aur scripts ka folder hai, sirf zaroorat par load.
  3. Achhi descriptions skills ko sahi waqt chalaati hain.
  4. Teesre ki skills install se pehle padho; company skills plugins se baanto.
