MCP: The Universal PlugMCP: Universal Plug

Haron learned to use tools in Chapter 16. But every app that wanted Haron to use GitHub, Google Drive, Slack or your company database had to write its own connector, again and again. The Model Context Protocol (MCP) fixes that, the way USB-C fixed chargers: a tool provider writes one MCP server, and every AI app that speaks MCP (Claude, ChatGPT, Cursor, VS Code, your own agent) can plug it in.

Haron ne Chapter 16 mein tools use karna seekha. Par har app jo chahti thi ki Haron GitHub, Google Drive, Slack ya company database use kare, use apna connector baar-baar likhna padta tha. Model Context Protocol (MCP) ise theek karta hai, jaise USB-C ne chargers theek kiye: tool banane wala ek MCP server likhta hai, aur MCP bolne wali har AI app (Claude, ChatGPT, Cursor, VS Code, aapka apna agent) use laga sakti hai.

The conversation between client and serverClient aur server ki baatcheet

Under the hood MCP is simple: JSON messages (JSON-RPC 2.0), one per line, over standard input/output for local servers or HTTP for remote ones. This chapter's lab is a complete server in 60 lines of plain Python, so you can see every message. These are the real messages from running it.

Andar se MCP seedha hai: JSON messages (JSON-RPC 2.0), ek line mein ek, local servers ke liye standard input/output par ya remote ke liye HTTP par. Is chapter ka lab seedhe Python ki 60 lines mein poora server hai, taaki aap har message dekh sako. Yeh use chalaane ke asli messages hain.

AI behaviour

Too many servers make Haron worseZyaada servers Haron ko kharab banaate hain

Each connected server adds its tool descriptions to every request. Connect ten servers with 15 tools each and Haron sees 150 tools: thousands of tokens, slower answers, and more wrong-tool choices. Connect only what the task needs, or use tool search (load tool definitions on demand) when there are many.

Har juda server har request mein apne tool descriptions jodta hai. 15 tools wale das servers jodo toh Haron 150 tools dekhta hai: hazaaron tokens, dheeme jawab, aur zyaada galat-tool chunav. Sirf wahi jodo jo kaam ko chahiye, ya bahut hon toh tool search use karo (tool definitions zaroorat par load).

In the real world

An MCP server is third-party code with your keysMCP server aapki keys ke saath teesre ka code hai

Risks: a malicious server can return text that hijacks the model (prompt injection), change its tool descriptions after you approved it, or simply exfiltrate the data you send it. Use servers from trusted publishers, pin versions, give each its own least-privilege credentials (remote servers use OAuth), log every call, and keep a company allowlist. If you skip MCP and hard-code integrations, you avoid this supply chain but rebuild every connector yourself.

Khatre: bura server aisa text lauta sakta hai jo model ko bhatkaaye (prompt injection), aapke approve karne ke baad apne tool descriptions badal sakta hai, ya bas bheja gaya data chura sakta hai. Bharosemand publishers ke servers lo, versions pin karo, har ek ko apne kam-se-kam permission wale credentials do (remote servers OAuth use karte hain), har call log karo, aur company allowlist rakho. MCP chhod kar integrations hard-code karo toh yeh supply chain bachti hai par har connector khud dobara banana padta hai.

The same server with the official Python SDK · pip install mcppython
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("leave-server")
LEAVE = {"E100": 12, "E200": 3}

@mcp.tool()
def leave_balance(employee_id: str) -> str:
    """Get the remaining paid-leave days for an employee ID like E100."""
    return f"{employee_id} has {LEAVE.get(employee_id, 0)} leave days left"

if __name__ == "__main__":
    mcp.run()          # stdio by default

What we learnedHumne kya seekha

  1. MCP is a standard plug between AI apps (clients) and tools or data (servers).
  2. Without it, every app rebuilds every connector: N × M instead of N + M.
  3. Under the hood: JSON-RPC messages for initialize, list tools, call tools.
  4. Connect only what you need, and treat every server like a vendor with your keys.
  1. MCP AI apps (clients) aur tools ya data (servers) ke beech standard plug hai.
  2. Iske bina har app har connector dobara banati hai: N + M ki jagah N × M.
  3. Andar se: initialize, tools list, tools call ke JSON-RPC messages.
  4. Sirf zaroori jodo, aur har server ko aapki keys wale vendor ki tarah dekho.
