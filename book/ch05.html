What a Harness IsHarness Kya Hai

Haron has cousins: Claude, GPT, Gemini, Llama, Qwen. They are all brains of the same kind, but each speaks a slightly different dialect when you send it messages and tools. A company that wants freedom to switch needs one team that speaks to all of them. In Part II, we build that team in Python, one piece per chapter. The code lives in code/harness/ and runs without any API key.

Haron ke cousins hain: Claude, GPT, Gemini, Llama, Qwen. Sab ek hi tarah ke dimaag hain, par messages aur tools bhejte waqt har ek thodi alag boli bolta hai. Jo company model badalne ki aazaadi chahti hai, use aisi team chahiye jo sabse baat kar sake. Part II mein hum woh team Python mein banaayenge, har chapter mein ek hissa. Code code/harness/ mein hai aur bina API key ke chalta hai.

The travel adapterTravel adapter

When you travel abroad, you don't rewire your phone charger; you carry an adapter. The harness does the same: inside, everything uses one neutral Message format. Only at the very edge does a small provider adapter translate it into each model's dialect.

Videsh jaate waqt aap phone charger ki wiring nahi badalte; adapter le jaate ho. Harness bhi yahi karta hai: andar sab kuch ek neutral Message format mein hai. Sirf bilkul kinaare par ek chhota provider adapter use har model ki boli mein translate karta hai.

Harness note

Normalise at the edge, but keep capability flagsKinaare par normalise karo, par capability flags rakho

Providers differ in more than syntax: where the system prompt goes, how parallel tool results are returned, whether temperature is accepted, how caching is turned on, what stop reasons mean. Translate the common core, but let each adapter declare what it supports (caching, effort, sampling knobs, vision), so the rest of the harness can choose instead of guessing.

Providers mein farak sirf syntax ka nahi: system prompt kahan jaata hai, parallel tool results kaise lautte hain, temperature accept hota hai ya nahi, caching kaise on hoti hai, stop reasons ka matlab kya hai. Common core translate karo, par har adapter batayein ki woh kya support karta hai (caching, effort, sampling knobs, vision), taaki baaki harness andaaza nahi, chunav kare.

Enterprise

Freedom to switch is a negotiating positionBadalne ki aazaadi ek mol-bhaav ki taakat hai

A company whose agents only work with one provider has no leverage on price, region or terms. With a clean adapter layer and evals per provider (Chapter 16), you can move a workload in days. Don't chase the lowest common denominator, though: use each provider's best features behind capability flags.

Jis company ke agents sirf ek provider ke saath chalte hain, uske paas daam, region ya sharton par koi taakat nahi. Saaf adapter layer aur har provider ke evals (Chapter 16) ke saath aap kaam ko dinon mein shift kar sakte ho. Par sabse neeche ke common denominator ke peeche mat bhaago: har provider ki best features capability flags ke peeche use karo.

What we learnedHumne kya seekha

  1. My cousins speak different dialects. The team uses one neutral language inside.
  2. Small adapters translate only at the edge.
  3. The team has layers: interface, session, loop, context, tools, policy, adapters, with budget and telemetry alongside.
  4. Being able to switch models keeps a company free.
  1. Mere cousins alag boliyaan bolte hain. Team andar ek neutral bhasha use karti hai.
  2. Chhote adapters sirf kinaare par translate karte hain.
  3. Team ki layers hain: interface, session, loop, context, tools, policy, adapters, aur saath mein budget aur telemetry.
  4. Model badal paana company ko aazaad rakhta hai.
